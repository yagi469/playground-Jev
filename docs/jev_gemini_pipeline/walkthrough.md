# Jev × Gemini 二段構え推敲パイプライン 完成報告 (Walkthrough)

**TypeSafe (Jev)** による高速・多面的な客観診断と、**Google Gemini 2.5 Flash**（Google Developer Program の月額クレジット特典を活用）によるピンポイント改善リライトを連携させた、**System One + System Two** の二段構えパイプラインを実装・検証しました。

---

## 1. アーキテクチャと連携フロー

1. **Jev (System One / 所要時間 約 747 ms)**
   - 記事の下書きを受け取り、文体トーン（Choice）、引きの強さ（Score）、難易度（Score）、具体例の有無（Noul）、誤解・炎上リスク（Noul）を1リクエストで並列評価。
2. **コードによる弱点・改善課題の自動検出**
   - Jev の判定数値から、「過度な断定や誤解を招く表現による炎上・反発リスクがある」「冒頭の引きが弱い」などの改善ポイントを自動抽出。
3. **Gemini 2.5 Flash (System Two / 推論 & 生成)**
   - Jev が特定した客観的な課題リストをプロンプトとして受け取り、元の文章の個性を活かしつつ課題を解消した「改善リライト案」「改善ポイント解説（3点）」「編集長からの助言」を JSON 形式で生成。
4. **Web UI による統合表示**
   - Jev の評価結果の下に「✨ Gemini 2.5 で弱点を改善・リライト」ボタンが表示され、ワンクリックで推敲リライト結果が可視化されます（ワンクリックコピー機能付き）。

---

## 2. 実機検証結果

### 入力したブログ記事テキスト（State）:
> 「最近話題の生成AIですが、ぶっちゃけ仕事で使い物になるのか疑問に思っている人も多いのではないでしょうか。私自身、最初は『所詮はお遊びのおもちゃ』と高をくくっていました。しかし、先月導入された新機能を使ってAPI連携を試してみたところ、これまで3時間かかっていた日報作成とログ解析がわずか5分で完了したのです。この記事では、私が実際に業務自動化を達成した手順と、つまずきやすい落とし穴を具体的に解説します。」

### Jev の客観診断:
- **文体トーン**: `casual_friendly` (親しみやすい語り口)
- **導入の引き**: `1.93` (普通〜魅力的)
- **難易度**: `1.00` (一般的なIT知識があれば読める)
- **具体的な学び・ノウハウ**: `Yes 98%`
- **誤解・反発リスク**: `Yes 63%`（⚠️ 読者からの反発・誇大感リスクを検出）

### Gemini 2.5 Flash による改善リライト結果:
- **検出された改善課題**:  
  `⚠️ 過度な断定や誤解を招く表現による炎上・反発リスクがある`
- **改善リライト案**:  
  > 「最近話題の生成AIですが、『ぶっちゃけ仕事で使えるの？』と疑問に感じている方も多いのではないでしょうか。私自身、最初は『所詮はお遊びのおもちゃ』と高をくくっていました。ところが、先月導入された新機能でAPI連携を試したところ、驚くべき結果が出ました。これまで3時間かかっていた日報作成とログ解析が、なんとわずか5分で完了したのです。この記事では、この劇的な変化を可能にした具体的な業務自動化の手順と、誰もがつまずきやすい実践上の落とし穴について、私の実体験に基づいて徹底解説します。」
- **改善ポイントの解説**:
  1. 冒頭の問いかけを読者の心情を代弁する形に修正し、決めつけ感を低減。
  2. 時間短縮の表現に「驚くべき結果」「なんと」を加え、普遍的な効果ではなく自身の体験であることを明示して誇大感を解消。
  3. 「誰もがつまずきやすい実践上の落とし穴」と表現を補強し、実装の難しさにも踏み込む誠実な姿勢を提示。
- **編集長の助言**:  
  > 「読者の期待値を適切に設定し、成功と課題の両面を提示するバランス感覚が、信頼性の高いコンテンツを生み出す上で不可欠です。」
