## 1. 実装の概要

### 対象ファイル
- [youtube_to_blog.py](file:///c:/Users/user/Dev/playground-Jev/youtube_to_blog.py)
  - `rewrite_youtube_post_with_gemini`: Jevの弱点診断（行間不足、オピニオン不足、数理不足、置いてけぼりリスク）をプロンプトに動的注入して加筆リライトする推敲エンジン
  - `refine_youtube_blog_post`: 初稿採点 ➔ 足切り判定 ➔ リライト ➔ 再採点を合格ラインまで繰り返す自律改善ループ

## 3. 具体的にどう改善されたか？

1. **第7章「私（筆者）はどう考えるか？――数理の深淵と残された問い」の新設**:
   - 会議の客観的サマリーを脱し、「代数と対称性が先頭を走り、背後から時空という幾何学が影のように立ち現れる美しさ」と、「観測とのアンカーを切り離したまま数学の深海を漂流していないかという危機感」を約2,000字にわたって熱烈に語る独自論考が加筆されました。
2. **途中計算（行間）の徹底解説**:
   - $T\bar{T}$変形におけるバーガース方程式の導出ステップ（円筒時空でのエネルギー準位微分と因数分解 contact term の相殺）など、数式の行間が初等的なステップで読者が追体験できるように解説されました。
3. **置いてけぼりリスクの激減**:
   - 初等的な物理概念（調和振動子、光円錐座標、熱量計による測定）との対比が入ったことで、置いてけぼりリスクが **86% ➔ 23%** へと劇的に低下しました。

## 5. 長尺動画向け「時間帯・特定セクション絞り込み」機能の追加

長時間の講義や複数人のシンポジウム動画で内容が薄まるのを防ぐため、特定の時間帯やテーマ・講演者のみを深く掘り下げて記事化するオプションを追加しました。

### 追加されたCLIオプション
- `--focus` / `-f`: 注目するセクション・テーマ・講演者（例: `"Andy StromingerのCelestial Holography"`）
- `--time` / `-t`: 対象時間帯（例: `"15:30-45:00"`, `"01:15:00-01:45:00"`）
- `--start`: 開始時間（例: `"15:30"`, `"930"`）
- `--end`: 終了時間（例: `"45:00"`, `"2700"`）

### 実装のポイント
1. **プロンプト制約の動的注入**:
   - NotebookLM プロンプトおよび Gemini リライトプロンプトに「指定された区間・トピック以外の前置きや他セクションは徹底的に排除し、該当内容の数式展開・背景思想を極限まで深掘りする」強いスコープ制約を注入。
2. **YouTube再生開始位置パラメータの自動付与**:
   - 記事内のYouTube埋め込み・参照リンクに自動で `&t={start_seconds}s` を付与し、読者が即座に対象シーンから視聴開始できるように対応。
3. **ファイル名サフィックスの自動化**:
   - 同一の長尺動画から複数のセクション記事を生成できるように、`YYYY-MM-DD-youtube-{video_id}-{section_slug}.md` として記事ファイルを分割保存可能。

## 6. 共通ノートブックの自動再利用とソース重複防止（高速化）

実行ごとに新規ノートブックが作成されて一覧が散らかるのを防止するため、共通ノートブック（デフォルト: `気になったYouTube動画`）を常に使い回す仕様に刷新しました。

### 実装のポイント
1. **共通ノートブックの自動検出・再利用**:
   - `DEFAULT_COMMON_NOTEBOOK = "気になったYouTube動画"` を標準とし、既存ノートブックを自動検索して再利用（`--notebook` オプションで任意ノートブックの指定も可能）。
2. **YouTube oEmbed API による高速タイトル照合 ＆ ソース取り込みスキップ**:
   - YouTube動画のタイトルをAPIキー不要の oEmbed 経由で即座に取得。
   - 共通ノートブック内に同タイトルの動画ソースが既に取り込まれている場合、時間のかかる `source add` を完全にスキップし、既存の `source_id` を再利用（劇的な実行高速化）。
3. **ピンポイントなレポート生成（`--source-ids` 連携）**:
   - 共通ノートブック内に多数の他動画ソースが存在しても、今回対象の `source_id` のみを `--source-ids` に渡してレポート生成するため、他の動画内容と混ざることがありません。
4. **新規ノートブック作成オプション（後方互換）**:
   - あえて専用ノートブックを作りたい場合は `--new-notebook` フラグで対応可能。
