# TypeSafe (Jev) Web UI プレイグラウンド 完成報告 (Walkthrough)

TypeSafe (Jev) の **Choice / Score / Noul** の3つのプリミティブをブラウザ上でインタラクティブに並列評価・リアルタイム可視化できる Web UI プレイグラウンドを実装・検証しました。

---

## 1. 実装内容

### バックエンド (`FastAPI`)
- **`backend/app.py`**:
  - `typesafe-sdk` と `.env.local` の API キーをロードして Jev (System One) と通信
  - `/api/presets`: ユースケース別プリセット定義の提供（カスタマーサポート分析、投稿モデレーション、レビュー分析）
  - `/api/evaluate`: テキスト（State）と質問定義（Questions）を受け取り、Jev を呼び出して構造化結果・所要時間・トークン数を返却
  - フロントエンドの静的ファイル配信を統合

### フロントエンド (`Vanilla HTML5 / CSS3 / JS`)
- **`frontend/index.html`**: セマンティックなUIレイアウト
- **`frontend/style.css`**: ネオングラデーション、ガラスモフィズム（Glassmorphism）、プログレスバーアニメーションによる洗練されたダークモード
- **`frontend/app.js`**:
  - プリセット切り替え、APIリクエスト制御
  - **Choice**: 選択結果、各選択肢の確率バー（%）、Confidence（確信度）バッジ
  - **Score**: スコア連続値（0〜N）、各レベルの確率分布バー、Confidence
  - **Noul**: Yes/No 判定の確率メーターと状態判定
  - レスポンス所要時間 (ms) およびトークン利用量のリアルタイム HUD

### サーバー起動スクリプト
- **`run_server.py`**: `http://localhost:8000` で Uvicorn をワンタッチ起動

## 2. 動作検証結果

ブラウザ自動検証により、以下の正常動作を確認しました：

1. **初期ロード & デザイン**:
   - ガラスモフィズムデザインとプリセットチップ、質問リストのプレビューが正常に描画されました。
2. **カスタマーサポート分析の評価実行**:
   - 所要時間 **約646ms** で判定完了
   - **Choice (担当部署)**: `billing` (確率: 100.0%, 確信度: 100%)
   - **Score (顧客のフラストレーション度)**: `1.98` (Lv.2 強い不満: 98.0%, 確信度: 98%)
   - **Noul (緊急対応の必要性)**: `Yes` (94.0%)
3. **プリセット切り替え（投稿モデレーション・安全性チェック）**:
   - 悪意あるリクエスト文に対し、即座に質問項目とテキストが同期
   - **Choice (種別)**: `exploit_attempt` (攻撃・不正アクセス / 100.0%)
   - **Score (リスク度)**: `2.81` (Lv.3 重大な脅威: 82.0%)
   - **Noul (即時ブロック要否)**: `Yes` (94.0%)

## 3. 起動・利用方法

サーバーは現在バックグラウンドで稼働中です。お好みのブラウザで以下のアドレスを開いてお試しいただけます：

```
http://localhost:8000
```

※ 後日再起動する場合は、プロジェクト直下で以下を実行してください：
```powershell
python run_server.py
```
